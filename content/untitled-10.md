# 日本政府が33年連続で「核兵器廃絶決議案」を国連に提出する理由、米国の「核の傘」に依存しながら核廃絶を訴える矛盾と非核三原則の行方


日本政府が、核兵器廃絶を目指す決議案を国連総会に提出した。1994年から33年連続となる取り組みだが、今年の決議案には例年とは異なる切迫した事情がある。核拡散防止条約（NPT）の再検討会議が3回連続で成果文書の採択に失敗し、核軍縮を支えてきた国際秩序が大きく揺らいでいるためだ。

一方、日本は世界で唯一の戦争被爆国として核廃絶を訴えながら、自国の安全保障ではアメリカの「核の傘」に依存している。核兵器禁止条約にも加盟していない。核兵器の廃絶を目指す外交と、核兵器による抑止を必要とする安全保障政策。この二つの立場を、日本政府はどう両立させようとしているのか。さらに、日本が国是として掲げてきた非核三原則との間に矛盾はないのだろうか。

## 核保有国に「軍縮義務の完全履行」を要求

日本政府は2026年10月19日、国連総会第1委員会（軍縮・国際安全保障）に核兵器廃絶を目指す決議案を提出したと発表した。共同通信によると、今回の決議案は核保有国に対して、NPTに基づく核軍縮交渉の義務を「完全に履行」するよう要請した。また、核軍縮交渉が進展していない現状について「深く憂慮」すると表明している。（[「日本、核廃絶目指す決議案提出 国連に、NPT体制空洞化懸念」共同通信、2026年10月20日付](https://news.jp/i/1485070137550553659?c=39550187727945729)）

その根拠となるのがNPT第6条だ。この条項は、核軍備競争の早期停止と核軍縮に関する効果的な措置などについて、各締約国が誠実に交渉する義務を定めている。

| 年 | 日本の決議案をめぐる動き |
| :---: | :---:|
| 1994年 | 国連総会への核廃絶決議案提出を開始 |
| 1995年 | NPTの無期限延長が決定 |
| 2010年 | NPT再検討会議で核軍縮の行動計画を採択 |
| 2017年 | 核兵器禁止条約が採択。日本は参加せず |
| 2022年 | 岸田文雄政権が「ヒロシマ・アクション・プラン」を提唱 |
| 2024年 | 日本提出の決議案が152カ国の賛成で採択 |
| 2025年 | 決議案が147カ国の賛成で採択 |
| 2026年 | 33年連続で提出、NPT再検討会議の決裂を反映 |

NPTは1970年に発効した。アメリカ、ロシア、イギリス、フランス、中国の5カ国を条約上の核兵器国と位置づけ、核兵器がそれ以外の国に拡散することを防ぐ一方、核軍縮を進めることも定めている。つまり、非核兵器国だけに核兵器を持たないよう求める条約ではない。核兵器国にも軍縮を進める責任がある。

しかし、核兵器国の軍縮は停滞している。とりわけ近年は、ロシアによるウクライナ侵攻、中国の核戦力増強、北朝鮮の核・ミサイル開発などによって、核兵器の役割が再び拡大する傾向にある。こうした状況で日本がNPT第6条の履行を強調したことは、核兵器国に対して軍縮の責任を改めて突きつける意味を持つ。

ただ、国連総会の決議はそれ自体が新たな法的義務を生むものではない。今回の決議案も核兵器国に対して具体的な削減期限を強制するものではなく、政治的な意思表明という性格が強い。

## NPT再検討会議が3回連続で決裂した背景

今回の決議案で最も重要な背景となったのが、2026年5月のNPT再検討会議の決裂だ。NPT再検討会議は原則として5年ごとに開催され、条約の履行状況を検証し、核軍縮や核不拡散を進めるための方針を話し合う。ところが、2015年、2022年、2026年と3回連続で、実質的な最終成果文書を採択できなかった。

| 年 | 決裂した主な原因 |
| :---: | :---: |
| 2015年 | 中東の非大量破壊兵器地帯をめぐる対立 |
| 2022年 | ロシアによるウクライナ侵攻とザポリージャ原発問題 |
| 2026年 | イランの核問題をめぐる米国とイランの対立など |

2015年は、中東に核兵器を含む大量破壊兵器のない地域を設ける構想をめぐって対立した。2022年には、ロシアが占拠したウクライナのザポリージャ原子力発電所に関する記述などが問題となり、ロシアが合意を妨げた。そして2026年は、イランの核問題が大きな障害となった。

4月27日から5月22日までニューヨークで開催された会議では、アメリカがイランの核不拡散義務の履行状況を問題視した。一方、イランは自国の核開発に対する批判に反発し、アメリカとイスラエルによる核施設への攻撃を非難した。最終文書案には、イランが核兵器を追求、開発、取得してはならないとする記述が含まれていたが、米国とイランの対立は解消しなかった。議長を務めたベトナムのドー・フン・ビエット国連大使は、合意は不可能と判断し、文書案を採択にかけなかった。

重要なのは、NPTそのものが失効したわけではないことだ。条約は引き続き有効だが、核軍縮の具体的な進め方について合意できなくなっている。核兵器国と非核兵器国の信頼関係が崩れ、NPT体制の空洞化が進んでいるのである。

## 日本が1994年から決議案を出し続ける理由

そもそも、日本政府が国連総会に核兵器廃絶決議案を提出し始めたのは1994年だ。冷戦終結後、アメリカとロシアの核軍縮が進展し、核兵器削減に対する国際社会の期待が高まっていた時期だった。1995年にはNPTの無期限延長を決定する会議が控えており、日本も核軍縮と核不拡散を進める外交を強化する必要があった。以来、日本は毎年、国際情勢に応じて内容を修正しながら、核廃絶決議案を提出してきた。

近年の決議案に盛り込まれているのは、核兵器の不使用の継続、核戦力に関する透明性の向上、核兵器用核分裂性物質生産禁止条約（FMCT）の交渉開始、被爆の実相を伝える軍縮・不拡散教育などである。これらは2022年に岸田文雄首相が提唱した「ヒロシマ・アクション・プラン」にも含まれる。

日本政府は、核兵器をただちに全面禁止するのではなく、核兵器国も参加できる形で段階的に核軍縮を進める方法を重視している。外務省が「現実的かつ実践的な取組」と説明する外交方針だ。

 **2024～25年の決議案に盛り込まれた主な措置** 
| 措置 | 内容 |
| :---: | :---: |
| 核兵器の不使用 | 核兵器を再び使用しないこと、核使用を示唆する威嚇的な言動を抑えること |
| 核戦力の透明性 | 核兵器数、核政策、核能力などの情報公開を促進すること |
| FMCT | 核兵器用の核分裂性物質の生産を禁止する条約の交渉開始 |
| CTBT | 包括的核実験禁止条約の早期発効と核実験停止の維持 |
| 核軍縮教育 | 広島・長崎の被爆の実相を世界に伝えること |
| 北朝鮮問題 | 北朝鮮にNPTやIAEA保障措置への復帰を求めること |

2024年の日本提出決議は国連総会本会議で152カ国、2025年には147カ国の賛成を得て採択された。ここで特徴的なのは、アメリカやイギリスなどの核兵器国に加え、米国の同盟国、核兵器禁止条約を推進する国々からも支持を集めていることだ。日本政府は、この幅広い支持に外交的な意義を見いだしている。核兵器国と非核兵器国の対立が深まる中、その両者を結びつける「橋渡し役」を果たそうというのである。

ただし、この方法には弱点もある。異なる立場の国々から賛成を得るには、強い拘束力を持つ要求や、核兵器の廃絶期限を明示することが難しい。幅広い賛成を集めることと、核軍縮を実際に進展させることは、必ずしも同じではないということだ。

## なぜ日本は核兵器禁止条約に消極的なのか

今回の決議案で、もう一つ注目されるのが核兵器禁止条約への言及である。共同通信によると、日本政府は同条約の採択や発効に「留意する」という表現を用いるにとどめた。核兵器禁止条約は2017年に国連で採択され、2021年に発効した。核兵器の開発、実験、生産、取得、保有、使用、使用の威嚇などを禁止している。NPTが核兵器国の存在を条約上認めながら軍縮を進める仕組みであるのに対し、核兵器禁止条約は核兵器そのものを違法なものとして禁止することを目指す。

両者は核兵器のない世界を最終的な目標とする点では共通しているが、その実現方法が異なる。核兵器禁止条約の第1回再検討会議は、2026年11月30日から12月4日までニューヨークで開かれる予定だ。しかし日本政府は、条約への加盟だけでなく、会議へのオブザーバー参加にも慎重な姿勢を示している。最大の理由は、日本の安全保障がアメリカの核抑止力に依存していることにある。

核兵器禁止条約は、核兵器の使用や使用の威嚇などを禁止している。一方、日本は核兵器を保有していないものの、米国が核兵器を使用する可能性を含む抑止力によって、自国への攻撃を防ごうとしている。そのため、現在の安全保障政策を維持したまま核兵器禁止条約に加盟することは難しい。

さらに、日本政府は核兵器国が参加しない核兵器禁止条約だけでは、実際の核兵器削減につながりにくいと考えている。しかし、核兵器禁止条約を支持する国々からすれば、核廃絶を訴える日本が核兵器の使用可能性に依存し続けることは、矛盾しているように映る。日本政府が「留意する」という控えめな表現にとどめている背景には、こうした難しい外交上の立場があると考えられる。

## 非核三原則と核の傘は矛盾するのか

では、日本が国是として掲げてきた非核三原則と、今回の決議案は矛盾するのだろうか。非核三原則とは、核兵器を「持たず、作らず、持ち込ませず」という三つの原則である。1967年に佐藤栄作首相が表明し、1971年には衆議院で非核三原則を順守する趣旨の決議が採択された。

今回の国連決議案が求める核軍縮は、核兵器を持たず、作らないという日本の政策と基本的に一致している。また、非核三原則は日本自身の核兵器政策であり、国連決議案は国際社会全体に核軍縮を促すものだ。したがって、両者が直接矛盾するわけではない。

問題になるのは、むしろアメリカの「核の傘」との関係である。日本は核兵器を保有しないが、米国が核兵器を含む軍事力によって日本への攻撃を抑止する仕組みに依存している。これは「拡大抑止」と呼ばれる。

日本政府は、米国の核抑止力に依存することと、将来的な核兵器廃絶を目指すことは両立すると説明してきた。核兵器が存在する以上、その脅威に備える必要がある。しかし、そのことは将来の核廃絶という目標を否定しない、という論理だ。この説明は、現在の安全保障環境を前提とすれば一定の整合性を持つ。

ただし、核兵器の使用を否定する一方で、いざという場合には米国が核兵器を使用する可能性によって日本の安全を守ろうとする構図は残る。それは、法的な矛盾というより、核兵器廃絶の理念と現実の安全保障政策との間に存在する政治的な矛盾である。

## 「持ち込ませず」が今後の焦点になる

さらに重要なのは、非核三原則の第三原則である「持ち込ませず」だ。米国の核の傘に依存すること自体は、米国の核兵器を日本国内に配備することを必ずしも意味しない。しかし、仮に日本国内への核兵器配備を認めたり、NATO型の核共有を導入したりする場合には、非核三原則との整合性が問題となる。

核共有とは、米国などの核兵器を同盟国の防衛に組み込み、一定の条件の下で運用に関与する仕組みを指す。NATOでは米国の核兵器が一部の加盟国に配備されているが、日本が同様の仕組みを導入すれば、「持ち込ませず」という原則の見直しが必要になる。さらに、核兵器の管理権限や運用への関与の仕方によっては、NPT上の義務との関係も検討しなければならない。

仮に日本が非核三原則を見直したとしても、それだけで直ちにNPT違反となるわけではない。しかし、国連では核兵器廃絶を訴えながら、自国では核兵器の配備を認めることになれば、日本の核軍縮外交に対する国際的な評価は大きく変わる可能性がある。

その意味で、非核三原則をめぐる国内の議論と、国連での核廃絶決議案は、切り離して考えることができない問題になっている。

## 日本は核廃絶と核抑止の両立をいつまで続けられるのか

日本が1994年に核兵器廃絶決議案の提出を始めた当時、冷戦は終結し、米ロ間の核軍縮が進んでいた。核兵器の役割は次第に縮小し、将来的な核廃絶に向けた国際的な合意が広がることが期待されていた。

ところが、現在は大きく異なる。ロシアは核兵器による威嚇を繰り返し、中国は核戦力を増強している。北朝鮮も核開発を継続している。米ロ間の軍備管理体制も弱体化した。核軍縮の必要性が高まる一方で、核保有国は核兵器を手放そうとしない。そして日本自身も、安全保障環境が厳しくなるほどアメリカの核抑止力への依存を強めざるを得ないという難題を抱えている。

今回の決議案は、そうした国際環境の中でも、NPTを核軍縮の中心的な枠組みとして維持しようとする日本の外交努力といえる。しかし、NPT再検討会議が3回連続で決裂した現実を考えれば、国連総会で多数の賛成を集めるだけでは十分ではない。

核兵器国が実際に軍縮義務を履行する仕組みをどう作るのか。核兵器禁止条約を推進する国々との溝をどう埋めるのか。そして、日本自身が核抑止力への依存を将来どのように減らしていくのか。こうした問いに答えなければ、日本が掲げる「核兵器のない世界」は、いつまでも遠い理想のままとなる。

日本政府は、核兵器国と非核兵器国の橋渡し役を自任している。しかし、橋渡しとは、双方の意見を取り入れた決議案を毎年提出することだけではない。核兵器の廃絶を求める理念と、核兵器に依存する安全保障政策との間にある隔たりを、自国の政策を含めてどう縮めていくか。

33年連続となる国連への決議案提出は、日本外交そのものに、その答えを問いかけている。
